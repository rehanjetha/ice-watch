# Validation

This is an early-stage prototype. Current validation includes controlled and outdoor sensor tests. Future work includes larger winter trials, enclosure durability testing, battery optimization, and facilities-user feedback.

## Current Evidence

| Area | What was tested | Result |
| --- | --- | --- |
| Controlled sensor validation | Temperature/moisture readings across dry, wet, and submerged conditions | 8/9 expected outcomes; all trials were distinguishable |
| Outdoor node testing | Housed electronics, portable power, and WiFi transmission outside | 10/10 trials returned consistent readings |
| Interface validation | Hazard map, alerts, and safer/direct route comparison | Hazards were easy to identify; route guidance needs stronger persuasion |

## Key Lessons

- The heatmap communicates risk quickly.
- Sensor placement matters as much as sensor selection.
- Route UX has to fight the user instinct to pick the shortest path.
- A production version needs longer winter exposure, not just short outdoor tests.

## Next Validation Work

- Larger winter trials across more walkway surfaces.
- Enclosure durability and water-ingress testing.
- Battery and power-cycle testing.
- Facilities-user workflow testing.
- Longer-term calibration against real maintenance and weather events.
