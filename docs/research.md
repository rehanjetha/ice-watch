# Research

IceWatch targets a narrow problem: walkway risk is local, but most winter information is broad or delayed.

## User Signals

| Signal | Finding |
| --- | --- |
| Survey size | 26 respondents |
| Repeated slips | 65.4% reported slipping multiple times |
| Slip anxiety | More than 96% had either slipped or feared slipping |
| Highest-risk area | Main walkways between buildings |
| Interview count | 6 interviews |

People described the same pattern repeatedly: slow down, shuffle, avoid paths connected to past slips, and mentally budget extra time when snow or freezing rain hides the surface.

## Product Rationale

IceWatch does not replace winter maintenance. It adds localized evidence so pedestrians and facilities teams can see where risk is forming.

| Existing approach | Gap |
| --- | --- |
| Salting/de-icing | Reactive and repeated; can increase runoff |
| Manual clearing | Useful but labor-limited |
| Plowing | Best for wider routes, weaker for hidden ice |
| Heated walkways | Preventative but expensive to retrofit |
| Ice cleats | Pushes responsibility onto the pedestrian |

## Concept Choice

A sensor-map system was selected because it is more deployable than mechanical snow-clearing concepts and more useful than passive warnings. The key value is the live connection between physical readings, map visualization, route choice, and future maintenance prioritization.
