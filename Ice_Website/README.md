# IceWatch Website

React/Vite app and local sensor-intake server.

## Run

```bash
npm ci
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start app and local API |
| `npm run check` | Run lint, typecheck, tests, build, and audit |

For the full project overview, use the [root README](../README.md).
